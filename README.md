# Sebastien Keisuke Bridonneau — CV website

This is a simple, one-page CV website built with HTML and a small amount of CSS.

## Preview locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Create a GitHub repository (for example, `cv`).
2. Upload `index.html` to the repository's top level.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. GitHub will show the published website address in the Pages settings.

If the repository is named `cv`, the address will usually be:
`https://YOUR-GITHUB-USERNAME.github.io/cv/`

## Learning the CSS

The CSS is inside the `<style>` section in the `<head>` of `index.html`.
The comments explain what each group of rules changes. Try changing one value at a time,
save the file, and refresh the browser to see the result.
